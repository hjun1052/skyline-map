Where CSLMapView saves your .cslmap files (Windows, macOS, Linux)

CSLMapView writes each export into a folder inside the Cities: Skylines install, which is a few levels deep on every system. Here is where to look and how to get there in a couple of keystrokes.

November 9, 2026

The folder

The mod saves exports to a folder named CSLMapView in the game's install folder, steamapps/common/Cities_Skylines. With Steam's default library:

SystemFolder
WindowsC:\Program Files (x86)\Steam\steamapps\common\Cities_Skylines\CSLMapView
macOS~/Library/Application Support/Steam/steamapps/common/Cities_Skylines/CSLMapView
Linux~/.local/share/Steam/steamapps/common/Cities_Skylines/CSLMapView

On macOS, ~/Library is hidden in Finder by default, which is why the file can seem to be missing.

If your Steam library is somewhere else

If you installed the game to another drive or library folder, let Steam find it for you:

  1. In Steam, right-click Cities: Skylines in your library.
  2. Choose Manage, then Browse local files.
  3. Open the CSLMapView folder.

The mod can also be pointed at a different output folder in its settings. If you or a friend changed that, the files are wherever it was set to.

What the files are called

Each export is named after your city. With the mod's timestamp setting on, the date and time are added, so exports never overwrite each other:

  • Sarrant.cslmap, without timestamps
  • Sarrant-20261107-234707.cslmap, exported on 7 November 2026 at 23:47:07
  • Sarrant-20261107-234707.cslmap.gz, the same with compression on

The compressed .gz files are much smaller. Skyline Map opens both kinds, so there is no need to unzip them. With timestamps, sort the folder by date to find your newest one.

The same folder holds the mod's Windows viewer, CSLMapView.exe, and its language folders. You can ignore those.

Jump to the folder from a file picker

You don't have to click through all those folders. Copy the path above, open the file picker (in Skyline Map, click Choose a .cslmap file), then:

  • macOS: press ⌘⇧G, paste with ⌘V and press Return.
  • Windows: press AltD to reach the address bar, paste with CtrlV and press Enter.
  • Linux (GTK file chooser): press CtrlL, paste and press Enter.

No file in the folder?

  • Check the mod is enabled in Content Manager, then export again from the mod's options with a city loaded.
  • Check the output folder setting in the mod's settings.
  • Look at the log. The mod writes CSLMapViewMod.log in the Cities_Skylines folder, one level up, which usually says what went wrong.
